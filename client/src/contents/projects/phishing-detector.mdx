# Phishing Website Detector

A rigorous machine learning pipeline that classifies URLs as phishing or legitimate using 46 carefully validated features. A key contribution was the detection and removal of 5 data-leaked features that caused artificially inflated 100% accuracy on initial naive models — demonstrating applied understanding of data leakage in real-world ML.
