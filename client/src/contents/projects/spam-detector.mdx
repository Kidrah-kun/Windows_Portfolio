# Spam Detection Engine

An end-to-end NLP pipeline for binary spam/ham text classification. Combines TF-IDF vocabulary representations with 9 custom structural features (message length, uppercase ratio, link count, exclamation marks, spam trigger word count, etc.) for robust classification. Deployed as an interactive Streamlit dashboard with real-time predictions.
