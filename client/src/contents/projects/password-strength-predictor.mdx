# Password Strength Predictor

A full-stack web application that evaluates password strength (Weak / Medium / Strong) in real time. Extracts 11 numerical and behavioral features from the password string — including Shannon entropy, keyboard pattern detection, and dictionary word matching — and passes them to a pre-trained Decision Tree classifier. Provides actionable per-feature feedback to help users improve their passwords.
