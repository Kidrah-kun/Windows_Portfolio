An automated resume screening system that parses resumes in PDF and DOCX formats, extracts key skills and experience, and ranks applicants against a job description using NLP similarity techniques. It combines semantic search, traditional ML classification, and LLM analysis via the Groq API.

## Key Highlights
- Calculates semantic similarity using Sentence Transformers (all-MiniLM-L6-v2) and cosine similarity.
- Extracts named entities (NER) and experience metadata using spaCy and Regex.
- Computes a weighted composite score combining similarity, keyword matching, and section completeness.
- Uses Random Forest for baseline resume category classification.
- Features an interactive Streamlit dashboard for HR personnel.
