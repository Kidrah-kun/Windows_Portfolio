# AI Resume Screener

An automated resume screening system that parses resumes in PDF and DOCX formats, extracts key skills and experience, and ranks applicants against a job description using NLP similarity techniques. Combines Sentence Transformer semantic search, traditional ML classification (Random Forest), named entity recognition (spaCy), and LLM-powered candidate analysis via the Groq API (LLaMA 3.3 70B).
